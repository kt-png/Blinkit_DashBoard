# 🛒 Blinkit Sales Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing Blinkit's grocery sales data using Microsoft Power BI. The objective is to transform raw sales data into meaningful business insights through interactive visualizations, KPI tracking, and data analysis.

The dashboard helps understand sales performance, product categories, outlet performance, and customer ratings to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track important business KPIs.
- Identify high-performing product categories.
- Compare sales across different outlet locations.
- Understand customer ratings and product preferences.
- Provide interactive reporting for business analysis.

## 🛠️ Tools & Technologies

- **Power BI Desktop:** Dashboard development and visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Measures and calculated columns.
- **Microsoft Excel:** Dataset management.
- **MySQL:** Data extraction and validation using SQL queries.

## 📊 Key Performance Indicators (KPIs)

The dashboard tracks four major KPIs:

| KPI | Description |
|---|---|
| Total Sales | Overall revenue generated |
| Average Sales | Average sales value |
| Number of Items | Total items analyzed |
| Average Rating | Average customer rating |

## 🔍 Dashboard Features

### 1. Sales Analysis
- Overall sales performance.
- Sales distribution across product categories.
- Comparison of different item types.

### 2. Product Analysis
- Item category performance.
- Fat content analysis.
- Product-level sales comparison.

### 3. Outlet Analysis
- Outlet location-based sales analysis.
- Outlet size comparison.
- Outlet establishment trends.
- Outlet performance evaluation.

### 4. Interactive Reporting
- Dynamic filters and slicers.
- Category-wise analysis.
- Outlet-level filtering.
- Interactive dashboard navigation.

## 🧹 Data Cleaning & Transformation

- Identified and handled missing values.
- Standardized inconsistent categorical values.
- Performed data transformation using Power Query.
- Validated data accuracy using SQL queries.
- Prepared the dataset for dashboard development.
